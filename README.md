# Grant America 2026

A modern web application built with Next.js, Tailwind CSS, and shadcn/ui components.

## Getting Started

### Prerequisites
- Node.js 20.9+ or later
- pnpm (recommended) or npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/njoshiga/grant-america-2026.git
cd grant-america-2026
```

2. Install dependencies:
```bash
pnpm install
# or
npm install
```

3. Run the development server:
```bash
pnpm dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Building for Production

```bash
pnpm build
pnpm start
```

## Deployment to Vercel

This project is optimized for deployment on [Vercel](https://vercel.com).

1. Push your code to GitHub (already done)
2. Visit [https://vercel.com/new](https://vercel.com/new)
3. Select your GitHub repository
4. Vercel will automatically detect Next.js and configure build settings
5. Click "Deploy"

## Tech Stack

- **Framework**: Next.js 16
- **Styling**: Tailwind CSS v4
- **UI Components**: shadcn/ui
- **Forms**: React Hook Form
- **Validation**: Zod
- **Icons**: Lucide React
- **Language**: TypeScript
